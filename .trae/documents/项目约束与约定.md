## 项目内容
- 技术栈：Astro + React 19 + TailwindCSS 4 + Font Awesome (React版)。
- 字体系统：自托管 ChillRoundF（显示/正文）。
- 主题：纯黑极简 + 翡翠绿强调的单一主题（MiniMal 风格）。

## 核心逻辑
- API 集成：统一 API 端点 `/api/bili-api.ts`。支持 `action=avatar` 代理获取 B站头像（解决 CORS/ORB 拦截）和直播状态检测。为了防爬虫，头像 URL 带有缓存机制，直播检测频率限制为 5 分钟/次。
- 动画逻辑：Hero 组件的直播脉冲圆环动画通过自定义 Hook `useLivePulse` 和 `requestAnimationFrame` 实现，样式逻辑解耦至 `utils/live-ring.ts`。

## 约束与警告
- B站 API 限制：服务器端请求 B站 API 易触发反爬（-352/-401），头像推荐手动下载至 `public/avatars/` 或通过带缓存的 API 代理。直接在 `<img>` 使用 B站 CDN 链接会被浏览器拦截。
