## 1. 产品概述

个人静态主页，支持双主题切换（MiniMal 极简黑金 / EndField 工业科技），展示个人信息、技能、项目、时间线和联系方式，集成 B站直播状态和头像。

- **目标用户**：希望拥有个人品牌展示页面的开发者/设计师
- **核心价值**：双主题可切换、模块化可配置、高性能静态站点 + B站深度集成
- **技术栈**：Astro 7 + React 19 + TailwindCSS 4 + Font Awesome + TypeScript

## 2. 核心功能

### 2.1 功能模块

1. **主题切换**：MiniMal（纯黑/金色/圆润）↔ EndField（深蓝黑/黄色警示色/工业风）实时切换
2. **加载动画**（EndField 主题专属）：竖直进度条 → 黄色扫屏 → 淡出显示主页
3. **英雄区（Hero）**：B站头像代理显示、直播脉冲圆环动画、直播状态检测
4. **导航系统**：MiniMal 顶部固定导航 / EndField 左侧悬浮伸缩侧边栏
5. **关于我**：个人介绍、核心数据统计
6. **技术栈**：技能标签云，按类别分组
7. **项目展示**：项目卡片网格，含预览链接
8. **时间线**：工作/教育经历时间线
9. **最新动态**：GitHub 动态或博客文章列表
10. **联系**：社交媒体链接（Font Awesome 图标）

## 4. 用户界面设计

### 4.1 MiniMal 主题设计

- **主题**：纯黑极简，黑底金字
- **主色**：白色 (#f5f5f5) 与灰色 (#a0a0a0, #666666) 层次
- **强调色**：金色 (#d4a843)，用于关键高亮和悬停状态
- **卡片**：深灰色 (#111111) 背景，微边框 (#1f1f1f)
- **字体**：Nunito（自托管变量字体，字重 200-1000）
- **导航**：顶部固定导航栏，滚动时毛玻璃效果
- **按钮**：简洁无边框风格，悬停有微光效

### 4.2 EndField 主题设计

- **主题**：工业科技感，参考《明日方舟：终末地》UI 风格
- **主色**：中性深色 (#080808)，Hero 背景浅灰 (#f5f5f5)，Footer 纯黑
- **强调色**：黄色 (#fffa00)，用于关键高亮和侧边栏
- **字体**：HarmonyOS Sans SC（自托管官方完整可变字体，字重 100-900）
- **导航**：左侧悬浮伸缩侧边栏（56px ↔ 224px），0.3s CSS 过渡动画
- **装饰元素**：L 形金色角标、卡片悬浮上移效果、CMYK 色条分隔线
- **加载动画**：竖直进度条（从上到下）→ 黄色扫屏（从左到右）→ 淡出

### 4.3 响应式设计

- 桌面优先设计，完美适配 1080p
- 平板：2列变为1列，调整间距
- 手机：全宽布局，堆叠排列，缩小字体和间距

## 5. 技术约束

### 5.1 字体
- 所有字体自托管，不使用 Google Fonts CDN
- HarmonyOS Sans SC 使用官方 TTF 完整可变字体

### 5.2 B站 API
- 头像通过 API 代理获取（解决浏览器 CORS/ORB 拦截）
- 头像 URL 缓存 1 小时降低请求频率
- 直播检测限制 5 分钟/次

### 5.3 主题切换
- 在 Astro Islands 架构下，主题状态通过 `data-theme` 属性 + `localStorage` 实现
- 直接 DOM 操作避免 React Context 在 Islands 间不互通的问题
