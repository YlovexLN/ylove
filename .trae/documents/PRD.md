## 1. 产品概述

个人静态主页，采用纯黑极简 + 翡翠绿强调的单一主题，展示个人信息、技能、项目、时间线和联系方式，集成 B站直播状态和头像。

- **目标用户**：希望拥有个人品牌展示页面的开发者/设计师
- **核心价值**：双主题可切换、模块化可配置、高性能静态站点 + B站深度集成
- **技术栈**：Astro 7 + React 19 + TailwindCSS 4 + Font Awesome + TypeScript

## 2. 核心功能

### 2.1 功能模块

1. **主题**：纯黑极简 + 翡翠绿强调（MiniMal 风格）
2. **英雄区（Hero）**：B站头像代理显示、直播脉冲圆环动画、直播状态检测
3. **导航系统**：顶部固定导航栏
4. **关于我**：个人介绍、核心数据统计
5. **技术栈**：技能标签云，按类别分组
6. **项目展示**：项目卡片网格，含预览链接
7. **时间线**：工作/教育经历时间线
8. **最新动态**：GitHub 动态或博客文章列表
9. **联系**：社交媒体链接（Font Awesome 图标）

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页 | 导航 | 顶部固定导航栏 |
| 主页 | 英雄区 | B站头像 + 直播脉冲圆环 + 姓名 + 简介 + 社交链接 |
| 主页 | 关于我 | 个人介绍文字 + 关键数据统计卡片 |

## 4. 用户界面设计

### 4.1 MiniMal 主题设计

- **主题**：纯黑极简，黑底 + 翡翠绿高亮
- **主色**：白色 (#f5f5f5) 与灰色 (#a0a0a0, #666666) 层次
- **强调色**：翡翠绿 (#34d399)，用于关键高亮和悬停状态
- **卡片**：深灰色 (#111111) 背景，微边框 (#1f1f1f)
- **字体**：Nunito（自托管变量字体，字重 200-1000）
- **导航**：顶部固定导航栏，滚动时毛玻璃效果
- **按钮**：简洁无边框风格，悬停有微光效

### 4.2 响应式设计

- 桌面优先设计，完美适配 1080p
- 平板：2列变为1列，调整间距
- 手机：全宽布局，堆叠排列，缩小字体和间距

## 5. 技术约束

### 5.1 字体
- 所有字体自托管，不使用 Google Fonts CDN
- 显示/正文使用 ChillRoundF（自托管 TTF）

### 5.2 B站 API
- 头像通过 API 代理获取（解决浏览器 CORS/ORB 拦截）
- 头像 URL 缓存 1 小时降低请求频率
- 直播检测限制 5 分钟/次
